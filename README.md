A simple ASP.NET Core Web API for managing employee data using CRUD operations.

## 📌 Tech Stack
- .NET 10
- C# 14
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- Swagger for API testing

## 🛠 Features
- Add new employee (POST /api/employee)
- Get all employees (GET /api/employee)
- Get employee by ID (GET /api/employee/{id})
- Update employee (PUT /api/employee/{id})
- Delete employee (DELETE /api/employee/{id})

## 🚀 Setup
1. Clone the repo  
2. Update connection string in `appsettings.example.json`  
3. Run migrations / create database  
4. Run project  
5. Test using Swagger

## 📝 Notes
This project uses DTOs and was built for learning ASP.NET Core Web API.
